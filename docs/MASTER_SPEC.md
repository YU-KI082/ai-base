# AI BASE MASTER SPEC v1.0

Vision: AI BASE is an AI-native media platform that helps users discover, compare, learn, and adopt AI tools. The platform is operated by multiple AI agents working together with human approval for sensitive actions.

## Design docs (canonical)

See [docs/README.md](./README.md) — especially SYSTEM_ARCHITECTURE, AGENT_ARCHITECTURE, EVENT_SYSTEM, DATABASE_SCHEMA, API_SPEC.

## Goals

- Become the default destination for discovering AI tools
- Monetize primarily through affiliate partnerships
- Build an AI-operated content company
- Global-first architecture
- LLM-vendor independence (OpenAI / Claude / Gemini / Grok / local)

## Agent Workflow

Scout → Reviewer → Writer → Designer → Translator → SEO → Draft → Human Approval → Publisher → Social → Analytics → Planner

## Final Principle

AI BASE is not a comparison website. It is an AI-operated company that continuously discovers, evaluates, explains, and recommends AI tools while humans supervise critical publishing decisions.
